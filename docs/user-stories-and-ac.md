# User Stories & Acceptance Criteria Analysis
**Project:** VLearn Adaptive Learning Studio (Day 18)  
**Document:** User Story & Acceptance Criteria Specification for 3 Solution Options  
**Methodology:** INVEST Standard + Gherkin Given-When-Then (BA Zone / Digital School standard)  
**Source Baseline:** [`three-option-design-sheet.md`](file:///home/dat/dev/vinuni_aia/Track1_Day18_2A202602721/three-option-design-sheet.md)

## 1. Executive Summary & Design Matrix

All three options share the exact same user profile, situation, task, and target outcome, but differ in mechanism, agency division, and interaction model:

- **Target Persona:** Non-tech learner (Marketing, Business Analyst transitioning into AI engineering) studying on VLearn.
- **Situation:** Blocked during Lesson 4 (*Building a Basic RAG Agent with LangChain*) at the VectorStore indexing step due to unfamiliarity with *"Embedding Dimension & Cosine Similarity"*.
- **Task:** Rapidly diagnose and patch the prerequisite knowledge gap without context-switching away from the workspace.
- **Desired Outcome:** Understand the core concept in under 3 minutes, regain cognitive confidence, and successfully resume code execution.

| Dimension | Option A: Diagnostic Refresher (AI-Led) | Option B: Knowledge Checklist (User-Led) | Option C: A/B Cognitive Contrast & Mentor Escalation (Co-create & Human) |
| :--- | :--- | :--- | :--- |
| **Interaction Pattern** | AI-driven mini-quiz & auto-synthesized refresher card | User-browsed prerequisite tree drawer & micro-lessons | Dialectical mental-model comparison & assisted mentor escalation |
| **Human-AI Agency** | **Ask:** AI evaluates answers and prescribes targeted micro-learning | **Don't Act:** System is passive; user exercises metacognition and chooses topics | **Ask:** User selects cognitive stance A vs B; confirms ticket escalation |
| **Primary Failure Mode** | Diagnostic misclassification | Incomplete prerequisite breakdown or user over/underestimation | Both mental models miss the learner's confusion point |
| **Recovery Path** | Instant "Skip to Lesson" / "Not what I need" bypass | One-click drawer dismiss `[X]` / link to full foundational lecture | Instant "Connect with Human Mentor" with auto-packaged context |

## 2. Option A: AI Diagnostic Refresher (AI-Led)

### 2.1. User Story

**US-VLEARN-01A: AI-Led Diagnostic Quiz and Refresher Card**

**As a** non-tech learner enrolled in the VLearn LangChain course who is blocked by unfamiliar prerequisite concepts,  
**I want to** take a 2-question diagnostic mini-quiz generated by the AI Tutor,  
**So that** I can automatically receive a 60-second targeted refresher card that resolves my specific confusion without having to search external documentation.

### 2.2. INVEST Self-Check

| Criteria | Evaluation | Status | Note |
| :--- | :--- | :---: | :--- |
| **Independent** | Self-contained within the lesson player interface; does not require prior completion of external modules. | ✅ | Decoupled from course grading and global LMS progress. |
| **Negotiable** | Allows adjusting the number of quiz questions (2 vs 3) and refresher length (30s vs 60s). | ✅ | Implementation details open to frontend presentation choice. |
| **Valuable** | Saves ~15-20 minutes of frustrated web searching; restores learning momentum in < 3 minutes. | ✅ | Directly addresses the blocker reported by learners in Day 17. |
| **Estimable** | Clear scope: trigger button, 2 quiz questions, scoring logic, refresher modal, recovery exit. | ✅ | Front-end and mock AI logic are well-defined. |
| **Small** | Scoped to a single interactive modal flow completed within 1 sprint. | ✅ | Sized for rapid testing and experimentation. |
| **Testable** | Clear input states, question evaluation criteria, and dismissal triggers for QA. | ✅ | Pass/fail criteria verifiable via Gherkin scenarios. |

### 2.3. Acceptance Criteria (Given-When-Then)

#### AC-01A-1: Happy Path — Complete Diagnostic Quiz & Receive Targeted Refresher
- **Given** the learner is on Lesson 4 (*RAG VectorStore Indexing*) and has encountered a blocker with *"Embedding Dimension & Cosine Similarity"*,
- **When** the learner clicks the *"Tôi vẫn chưa hiểu"* (I still don't understand) trigger button,
- **Then** the AI Tutor opens an overlay modal stating that it will ask 2 diagnostic questions within 60 seconds,
- **And** when the learner submits answers to both questions indicating confusion about Cosine Similarity calculation,
- **Then** the AI displays an evidence banner: *"Dựa trên bài học VectorStore và 2 câu trả lời của bạn, AI nhận thấy bạn đang vướng ở: Cosine Similarity"*,
- **And** presents a concise 60-second visual Refresher Card with a geometric analogy and code snippet,
- **And** provides a prominent *"Quay lại bài học"* (Return to Lesson) button that restores the exact code editor cursor position.

#### AC-01A-2: Edge Case — Ambiguous / Boundary Diagnostic Score (Uncertainty Handling)
- **Given** the learner has initiated the diagnostic quiz in Lesson 4,
- **When** the learner answers one question correctly (Vector Dimension) but hesitates or gives a borderline answer on Cosine Similarity,
- **Then** the system detects uncertainty and displays an explicit transparency note: *"AI chưa chắc chắn bạn đang vướng ở Khái niệm Vector hay Thuật toán Cosine"*,
- **And** the Refresher Card provides collapsible dual-tab summaries covering both concepts side-by-side rather than hallucinating a single forced diagnosis.

#### AC-01A-3: Negative / Recovery Path — Diagnostic Cancellation & Wrong Topic Bailout
- **Given** the learner has opened the diagnostic quiz modal or is viewing the generated Refresher Card,
- **When** the learner clicks *"Bỏ qua chẩn đoán, quay lại bài"* (Skip diagnosis) or *"Đây không phải phần tôi cần"* (Not what I need),
- **Then** the overlay closes immediately within 200ms without saving any penalty or altering course completion status,
- **And** the lesson player workspace is completely restored with all previous inputs intact.

## 3. Option B: Prerequisite Knowledge Checklist (User-Led)

### 3.1. User Story

**US-VLEARN-02B: User-Led Prerequisite Knowledge Breakdown Drawer**

**As a** self-directed non-tech learner encountering unfamiliar terms in the RAG lesson,  
**I want to** open a prerequisite checklist drawer that breaks down the lesson into transparent foundational building blocks,  
**So that** I can inspect and select the exact concept I feel uncertain about to view a visual micro-lesson at my own pace.

### 3.2. INVEST Self-Check

| Criteria | Evaluation | Status | Note |
| :--- | :--- | :---: | :--- |
| **Independent** | Operates as a non-modal slide-out drawer that can coexist with the lesson video and code workspace. | ✅ | No dependency on AI inference service or test scoring. |
| **Negotiable** | Concept tree depth, visual formats (diagrams vs code diffs), and bookmarking can be customized. | ✅ | Highly modular UI component. |
| **Valuable** | Empowers learner agency; avoids test anxiety and patronizing AI assumptions. | ✅ | Aligns with Linh's self-study workflow observed in Day 17. |
| **Estimable** | Standard hierarchical drawer pattern with static or pre-parsed prerequisite data fixtures. | ✅ | Straightforward implementation with clear UI boundaries. |
| **Small** | Can be constructed and tested within 1 sprint. | ✅ | Minimal complexity and zero external backend latency. |
| **Testable** | Clear click interactions, accordion/drawer expansion, and dismissal behaviors. | ✅ | Deterministic state transitions easily validated by QA. |

### 3.3. Acceptance Criteria (Given-When-Then)

#### AC-02B-1: Happy Path — Open Checklist Drawer & Inspect Specific Prerequisite Concept
- **Given** the learner is studying Lesson 4 in the VLearn player,
- **When** the learner clicks the *"Mắt xích kiến thức nền"* (Foundational Prerequisite Tree) tab on the right utility bar,
- **Then** a side drawer slides open displaying a checklist of prerequisite modules categorized into:
  - `[x] Vector Embeddings cơ bản (Bài 2)`
  - `[ ] Vector Dimension & Không gian đa chiều`
  - `[ ] Khoảng cách Cosine vs Euclidean Distance`,
- **When** the learner clicks on *"Khoảng cách Cosine vs Euclidean Distance"*,
- **Then** an inline card expands showing a visual ELI5 diagram, a 2-line Python snippet, and an exact cross-link: *"Trích xuất từ Bài 2: Nhập môn Vector Embeddings"*,
- **And** the main coding workspace remains interactive and visible side-by-side.

#### AC-02B-2: Edge Case — Multi-selection and Deep Dive Linkout
- **Given** the learner has opened the Knowledge Checklist drawer,
- **When** the learner selects multiple prerequisite checkboxes to review related concepts simultaneously,
- **Then** the drawer displays an aggregated mini-progress indicator showing reviewed vs remaining foundational concepts,
- **And** provides an optional action button *"Mở bài giảng gốc trong tab mới"* (Open original foundational lecture in new tab) without resetting current lesson code.

#### AC-02B-3: Negative / Recovery Path — Accidental Drawer Opening & State Reversion
- **Given** the learner has opened the Knowledge Checklist drawer and toggled several concept checkboxes,
- **When** the learner clicks the close icon `[X]`, presses the `Escape` key, or clicks outside the drawer overlay,
- **Then** the drawer dismisses smoothly without any modal confirmation blockage,
- **And** all checkbox states are saved in local session storage so returning to the drawer retains the learner's self-assessment marks.

## 4. Option C: Cognitive A/B Contrast & Mentor Escalation (Co-create & Human)

### 4.1. User Story

**US-VLEARN-03C: Dialectical Mental-Model Contrast & One-Click Mentor Escalation**

**As a** non-tech learner confused between similar concepts in the VectorStore configuration,  
**I want to** compare two contrasting mental models (Interpretation A vs Interpretation B) and have the option to escalate my exact context to a human teaching assistant,  
**So that** I can deconstruct my misconception through dialectical contrast and secure expert human intervention if self-study fails.

### 4.2. INVEST Self-Check

| Criteria | Evaluation | Status | Note |
| :--- | :--- | :---: | :--- |
| **Independent** | Operates as a contextual inspection widget; ticket creation interfaces with LMS support queue. | ✅ | Standalone frontend dialog with mock or live webhook payload. |
| **Negotiable** | The representation of Option A vs B (code vs mental analogy) and mentor SLA display can be tuned. | ✅ | Promotes rich pedagogical flexibility. |
| **Valuable** | Targets cognitive root causes (misconceptions) while providing an infallible human safety net. | ✅ | Directly captures Khánh and Thương's interview insights from Day 17. |
| **Estimable** | Combines an A/B choice radio component with an automated context-gathering payload generator. | ✅ | Readily estimated across frontend and support ticketing integrations. |
| **Small** | Fits into 1 development sprint for prototype evaluation and usability testing. | ✅ | Focused interaction scope with high evaluative signal. |
| **Testable** | Clear verification criteria for contrast selection, feedback generation, and ticket payload serialization. | ✅ | Comprehensive test scenarios covering both automated and human channels. |

### 4.3. Acceptance Criteria (Given-When-Then)

#### AC-03C-1: Happy Path — Contrast Common Mental Models & Resolve Misconception
- **Given** the learner is stuck on Vector Dimension mismatch errors in Lesson 4,
- **When** the learner clicks *"Đối chiếu cách hiểu"* (Compare Mental Models) beside the code editor,
- **Then** a comparison card displays two structured scenarios based on historical cohort mistakes:
  - **Cách hiểu A:** *"Vector Dimension đại diện cho số lượng từ ngữ trong văn bản"* (Word count),
  - **Cách hiểu B:** *"Vector Dimension đại diện cho số chiều đặc trưng ngữ nghĩa được cố định bởi embedding model"* (Semantic coordinate size),
- **When** the learner selects Option A and clicks *"Kiểm tra góc nhìn"*,
- **Then** the system highlights: *"68% học viên mới thường nhầm lẫn điểm này!"*, breaks down why Option A causes indexing errors, and demonstrates why Option B is correct using an interactive coordinate visualizer,
- **And** displays a success action: *"Tôi đã hiểu bản chất — Tiếp tục làm bài"*.

#### AC-03C-2: Edge Case — Neither Option Fits Learner's Confusion
- **Given** the learner is reviewing the A/B comparison card,
- **When** the learner feels that neither Option A nor Option B reflects their specific technical confusion,
- **Then** the card provides a secondary choice: *"Cả 2 cách hiểu trên đều không đúng thắc mắc của tôi"*,
- **And** immediately transitions the card to the Mentor Escalation form with an open 1-sentence note field.

#### AC-03C-3: Negative / Recovery Path — Human Teaching Assistant Escalation
- **Given** the learner has reviewed the explanation but remains blocked,
- **When** the learner clicks *"Vẫn chưa thông — Gửi Trợ giảng hỗ trợ 1-1"*,
- **Then** the system generates a draft ticket preview containing:
  - Current lesson name & timestamp,
  - Current code snippet and terminal error output,
  - The learner's chosen A/B option and note,
- **When** the learner reviews the preview and clicks *"Xác nhận gửi Mentor"*,
- **Then** the ticket is dispatched with a visible confirmation: *"Đã gửi context cho Trợ giảng trực ban (Thời gian phản hồi dự kiến: < 10 phút)"*,
- **And** provides an instant exit button back to the lesson workspace without locking the interface.

## 5. Traceability Matrix & Gate Alignment

| Design Sheet Requirement | Option A (AI Diagnostic) | Option B (Checklist Drawer) | Option C (A/B Contrast + Mentor) |
| :--- | :--- | :--- | :--- |
| **Gate 1: Evidence Continuity** | Addresses quiz/test friction identified with Khánh & Thương | Addresses Linh's self-directed checklist habit | Addresses Linh & Khánh's need for human mentor reassurance |
| **Gate 2: Mechanism Divergence** | AI-Led prescriptive testing | User-Led exploratory retrieval | Co-created dialectical contrast + Human-in-the-loop fallback |
| **Gate 3: Human Agency & Recovery** | AI Asks before quiz; instant skip button; no penalization | AI Don't Act; user-initiated drawer; persistent state | AI Asks A/B choice; preview before dispatch; human safety net |
| **Gate 4: Test Readiness** | Fully clickable 2-question quiz + refresher + return flow | Fully clickable tree items + expanding micro-lesson + close | Fully clickable A/B radio + comparison view + ticket dispatch |
| **Gate 5: Learning Signals** | Tests if learners feel judged by surprise quizzes | Tests if non-tech learners can identify their own blind spots | Tests if learners prefer peer misconceptions or immediate mentor help |
