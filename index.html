Bước 3: VectorStore Indexing

Yêu cầu: Khởi tạo VectorStore Chroma, thực hiện nhúng (embed) các đoạn văn bản (Chunks) bằng mô hình embedding và thực hiện truy vấn tương đồng (Similarity Search) với ngưỡng cosine_similarity >= 0.75.

rag_indexing.py Python 3.11 · LangChain 0.2 
from langchain_community.vectorstores import Chroma
from langchain_openai import OpenAIEmbeddings

# 1. Khởi tạo mô hình Embedding
embeddings = OpenAIEmbeddings(model="text-embedding-3-small")

# 2. Khởi tạo VectorStore Indexing
vector_store = Chroma.from_documents(
    documents=doc_chunks,
    embedding=embeddings,
    collection_name="knowledge_base"
)

# 3. Truy vấn tương đồng ngữ nghĩa
query = "Khung năng lực AI Product Manager gồm những gì?"
results = vector_store.similarity_search_with_relevance_scores(
    query=query, 
    k=3,
    score_threshold=0.75  # Ngưỡng Cosine Similarity
)

Refresher Card: Embedding Dimension & Cosine Similarity Tóm tắt 60s

1. Dimension (1536): Bất kể câu văn dài 3 từ hay đoạn văn dài 500 từ, mô hình embedding luôn nén ngữ nghĩa thành một điểm gồm 1536 tọa độ thực.

2. Cosine Similarity: Đo góc $\theta$ giữa 2 vector hướng. Nếu 2 đoạn văn cùng chung ý nghĩa ngữ cảnh, 2 mũi tên sẽ chỉ về cùng một hướng ($\cos \theta \to 1$), bất kể độ dài văn bản chênh lệch bao nhiêu.
